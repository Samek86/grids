# Grids

Windows용 빠르고 가벼운 다중 패널 파일 관리자입니다. 한 창에 탐색기 패널을 최대 16개 띄우고, 왼쪽 폴더 트리와 함께 끌기 한 번으로 배치를 바꿉니다. 설치 없이 exe 하나(약 450KB)로 실행됩니다.

각 패널이 실제 Windows 탐색기 화면이라 우클릭 메뉴, 끌어다 놓기, 썸네일, 이름 바꾸기, 복사 진행 표시가 탐색기와 똑같이 동작합니다.

## 기능

- **자유 배치**: 최대 4열, 열마다 1~4칸. 레이아웃 버튼을 클릭하면 균등 배치, 누른 채 끌면 열마다 칸 수 지정, 자주 쓰는 배치는 프리셋 6개.
- **크기 조절**: 패널 경계, 사이드바 가장자리, 폴더 트리와 즐겨찾기 사이 구분선을 끌어서 조절합니다. 경계 더블클릭은 균등 분할입니다.
- **왼쪽 패널**: 위는 폴더 트리, 아래는 즐겨찾기이고, 사이 구분선을 끌어 높이를 나눕니다. 각 부분은 최소 높이를 유지합니다. 비율은 `grids.json`의 `side_split`에 저장되어 다시 열 때 돌아옵니다. 패널 전체는 설정에서 숨깁니다.
- **폴더 트리**: 활성 패널 폴더를 따라가고, 깊은 폴더에서도 현재 폴더 이름이 보이게 스크롤.
- **패널별 도구줄**: 주소창, 뒤로/앞으로/상위, 이름 필터(`*.pdf;*.txt` 또는 이름 일부), 선택한 폴더를 다른 패널에서 열기(열 순서·폭·정렬도 함께 넘어가서 한 패널만 맞추고 복사하듯 쓸 수 있음)와 선택한 파일을 다른 패널 폴더로 복사·이동(최대 10,000개), 즐겨찾기. 폴더를 패널 윗줄에 끌어다 놓으면 그 패널에서 열림.
- **드라이브 버튼**: 위쪽 도구줄의 C: D: E: … 를 누르면 지금 패널에서 그 드라이브를 엽니다. 지금 패널의 드라이브에는 선택 색 밑줄이 붙고, 드라이브를 꽂거나 빼면 버튼이 저절로 생기고 사라집니다.
- **앞으로 가져오기**: Win+Alt+E 로 어느 앱에서나 Grids를 앞으로 가져오고, 다시 누르면 최소화합니다. Grids 대화 상자가 열려 있으면 그 창이 앞으로 옵니다. 보기 메뉴의 체크는 키가 실제로 등록됐을 때만 켜지므로, 시작에 실패해도 한 번 누르면 다시 시도합니다. 단축키는 설정에서 바꿀 수 있습니다. `grids.json`에 `hotkey`가 없으면 켜져 있는 것입니다.
- **세션**: 배치, 폴더, 패널별 열(순서·너비·정렬)은 자동 저장. 지워진 로컬 폴더는 남아 있는 가장 가까운 상위 폴더로 열리고, 상태줄에 어떤 폴더가 없었는지 나옵니다. 이름 붙인 세션을 저장하고, 배치 미리보기 카드에서 불러오기. 카드에 마우스를 올리면 나오는 ✕로 지우고, 오른쪽 클릭 → 이름 바꾸기로 카드 위에서 바로 이름을 고칩니다(이미 있는 이름은 덮어쓰지 않고 거부). 저장 안 된 배치 변경은 저장 버튼의 초록 점으로 표시.
- **파일 확장명**: 보기 메뉴의 '파일 확장명 표시'는 탐색기와 같은 Windows 설정입니다. 설정 창에도 있습니다.
- **열은 패널 설정**: 열 순서·폭·정렬이 패널을 따라가서 다른 폴더로 가도 그대로 유지되고, 탐색기보다 더 좁게 줄일 수 있음(탐색기에선 크기 열이 90px에서 멈춤).
- **빠른 미리보기 (F3)**: 사진·동영상 장면, 텍스트·소스 코드(줄 번호), 마크다운(제목·목록·코드), CSV/TSV 표, ZIP·폴더 목록, 그리고 Office·PDF·HTML·Outlook 메일·글꼴은 탐색기와 같은 미리보기 처리기로 보여 줍니다(charset 없는 UTF-8 HTML도 한글이 깨지지 않게 BOM을 붙입니다). 처리기가 없으면 Word·Excel·PowerPoint·OpenDocument는 본문이나 첫 시트, HWP·HWPX는 문서에 든 미리보기, .eml은 머리글과 본문입니다. 그 외는 큰 아이콘, 종류, 크기, 날짜, 프로그램 버전·바로가기 대상·URL이 담긴 카드입니다. 10 MB가 넘는 문서는 건너뜁니다. Esc는 여는 중에도 바로 닫습니다. 이 기능은 F3을 누르기 전에는 불러오지 않고, 미리보기를 닫으면 놓습니다.
- **패널 안의 탭** (보기 → 패널 안의 탭, 기본은 꺼짐): 패널 머리줄 아래에, 그 패널의 폴더를 담은 탭 줄이 생깁니다. 창 위쪽의 탭(Ctrl+T)과는 다릅니다. Ctrl+Alt+T나 +로 지금 폴더를 새 패널 탭으로 열고, Ctrl+Alt+W·×·가운데 클릭으로 닫고, Ctrl+Alt+Page Down / Page Up이나 클릭으로 옮겨 갑니다. 빈 줄을 더블클릭해도 새 패널 탭이 생깁니다. 키는 설정 → 단축키에 있고, 탭 줄이 켜져 있고 포커스가 그 패널에 있을 때만 동작해서 창 탭의 Ctrl+T·Ctrl+W, 패널 이동의 Ctrl+Page Down과는 겹치지 않습니다. 폴더는 `grids.json`(`pane_tabs`, 패널의 `folders`)과 이름 붙인 세션에 저장되고, 줄을 숨겨도 남습니다.
- **즐겨찾기**: 패널 머리줄의 별로 추가하거나, 파일·폴더를 우클릭해 속성 바로 위에서 즐겨찾기에 추가합니다. 왼쪽 패널 아래쪽이 그 트리입니다. 그룹을 만들고 중첩하고, 항목을 그룹 사이로 끌어 옮길 수 있습니다. 폴더를 두 번 누르면 이 창에서 열고, 파일은 기본 앱으로 엽니다. Ctrl+B도 같은 트리를 씁니다. `grids.json`의 `favorites_tree`에 저장되며, 예전 목록은 맨 위로 옮겨집니다.
- **폴더 크기**: 선택한 폴더의 전체 크기도 상태줄에 표시(뒤에서 계산, F5로 다시 계산, 읽지 못한 항목이 있으면 '일부만'이라고 표시).
- **라이트·다크 테마**: 테마마다 선택 색 6가지. 활성 패널은 테두리와 머리줄 색으로 구분. 다크에서는 '장치 및 드라이브' 같은 묶음 제목이 밝은 글자와 가는 선으로 그려집니다. 새로 설치하면 Windows 설정을 따릅니다. 보기 메뉴의 'Windows 라이트·다크 설정 따르기'가 그 체크입니다. 테마 버튼을 누르면 직접 고르고 따라가기를 끕니다. 목록은 그 자리에서 다시 칠하므로 이동 기록, 필터, 선택, 스크롤, 입력 중인 주소가 남습니다.
- **패널 색**: 패널 머리줄의 빈 곳이나 번호를 오른쪽 클릭하면 그 여섯 색(또는 없음) 중 하나를 고릅니다. 얇은 띠는 버튼 위 여백에만 들어가고, 번호는 그 색 칸 위에 그려집니다. 세션에 저장되며 탭 색과는 별개입니다. ⇄ 메뉴에 색 이름이 함께 나옵니다.
- **창**: Ctrl+N으로 같은 프로세스에 새 창을 엽니다. 창마다 탭이 따로입니다. 탭을 밖으로 끌거나 탭 메뉴로 옮깁니다. 마지막 창을 닫으면 모든 창이 다음 실행에 돌아오고, 그 외의 창은 그 창만 닫힙니다. `grids.exe`를 다시 실행해도 새 프로세스가 아니라 새 창이 열립니다. 설정 → 일반 → 창 하나만 쓰기(`grids.json`의 `one_window`, 없으면 꺼짐)를 켜면 창은 하나입니다. 다시 실행하면 최소화된 창을 복원하고, 경로 인자는 그 창의 탭으로 엽니다. Ctrl+N, 탭을 밖으로 끌기, 새 창으로 이동, 이미 앞에 있을 때의 Win+Alt+E는 새 창 대신 이 창의 탭을 엽니다.
- **포터블**: 설정은 `%APPDATA%\grids\grids.json`에 저장됩니다. exe 옆에 `portable.txt` 파일을 두면 `grids.json`을 exe 옆에 둡니다. 기존 `grids.ini`는 한 번 읽은 뒤 `grids.ini.bak`으로 바꿉니다. 이름 붙인 세션은 그대로 exe 옆 `sessions` 폴더의 `.grids` 파일입니다. 파일은 원자적으로 바뀌고, 저장이 실패하면 5초 뒤에 다시 시도합니다. 읽지 못하는 파일은 기본값으로 덮지 않고 다시 시도하거나 종료합니다. 최소화해도 최대화였으면 최대화로 기억합니다. 모르는 키는 그대로 둡니다.
- **설정**: 도구줄의 톱니, 또는 보기 → 설정. 언어는 자동(Windows 표시 언어), English, 한국어, 日本語이고 `"lang": "auto"`, `"en"`, `"ko"`, `"ja"`로 저장됩니다. 예전 `grids.ini`의 `lang=ko`도 한국어로 읽힙니다. 패널 안의 탐색기 부분(열 이름, 우클릭 메뉴 등)은 Windows 표시 언어를 따릅니다.

## 다운로드

[Releases](https://github.com/efww/grids/releases)에서 `grids.exe`를 받아 아무 폴더에 두고 실행하면 됩니다.

코드 서명이 없는 exe라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.

**요구 사항**: Windows 10(1903 이상) 또는 Windows 11, x64.

## 단축키

아래는 기본값이에요. 설정 → 단축키에서 바꿀 수 있고, 바꾼 키는 바로 동작해요. 주소창, 필터, 탭 이름을 입력하는 동안에는 단축키가 먹지 않아요. F6은 그 칸에서도 포커스를 옮깁니다. 다른 앱에 갔다 키보드로 돌아오면 목록, 주소, 필터, 폴더 트리, 즐겨찾기 중 떠나기 전 자리로 포커스가 돌아옵니다. 클릭으로 돌아오면 그 클릭이 컨트롤을 받지 않았을 때만 되돌립니다. 주소와 필터의 글자와 커서는 그대로입니다.

| 키 | 동작 |
| --- | --- |
| Ctrl+T | 새 탭 |
| Ctrl+W | 탭 닫기 (잠긴 탭은 그대로) |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl+Shift+T | 마지막으로 닫은 탭 다시 열기 |
| Ctrl+PageDown / Ctrl+PageUp | 다음 / 이전 패널 |
| Ctrl+1 … Ctrl+9 | 1~9번 패널로 이동 (패널 머리줄 왼쪽의 번호, 아주 좁은 패널에서는 생략) |
| Alt+Shift+← / → / ↑ / ↓ | 왼쪽·오른쪽·위·아래 패널로 이동 |
| Ctrl+Alt+Shift+← / → / ↑ / ↓ | 지금 패널을 그 방향의 패널과 자리 바꾸기 (폴더·방문 기록·필터·열이 유지되고, ⇄ → 자리 바꾸기에도 있음). 저장하거나 다시 바꾸기 전까지 저장 점이 남고, 다시 시작해도 그대로입니다 |
| Alt+← / Alt+→ | 뒤로 / 앞으로 |
| Alt+↑ | 상위 폴더 |
| Alt+↓ | 최근 폴더 (모든 패널, 최근 순, ← / → 오른쪽 클릭도 가능) |
| Ctrl+L, Alt+D, F4 | 주소창. 칸이 넓으면 왼쪽에 현재 폴더 아이콘이 붙습니다. 가만히 있으면 `C: › Users › Public`처럼 경로 조각으로 보여요. 조각을 누르면 그 폴더로, › 는 그 안의 폴더 목록(지금 패널이 연 폴더는 굵게), `…`는 접힌 상위 폴더, 현재 폴더나 빈 곳은 경로 입력. 느린 폴더도 창을 멈추지 않고, 메뉴 위치는 열기 직전에 다시 잡습니다. 창 크기나 DPI가 바뀌면 취소됩니다. `..`, 하위 폴더, 열 파일, `cmd`·`wt`·`powershell`도 가능(이 패널 폴더에서 실행). `down`처럼 이름 일부만 치면 최근 폴더, 없으면 즐겨찾기 트리의 폴더로 이동합니다 |
| Ctrl+F | 이 폴더를 검색합니다(같은 칸이 목록 필터이기도 합니다). 비어 있으면 '검색 · Ctrl+F'가 흐리게 보이고, 입력하거나 포커스를 주면 사라집니다. 단어는 이름 어디에든 맞고, `*`와 `?`는 와일드카드, `;`는 둘 중 하나이며, 대소문자는 구분하지 않습니다. 입력하는 동안 결과가 이어지고, 다시 입력하거나 Esc면 검색이 취소됩니다. 결과는 300개에서 멈추고 더 있다고 알려 줍니다. Enter나 더블클릭은 파일을 열고(그 파일이 있는 폴더로 패널이 이동합니다) 폴더는 이 패널에서 엽니다. 결과 목록의 하위 폴더는 아래 폴더까지 찾습니다. Everything이 실행 중이면 그쪽으로 묻고, 아니면 Grids가 폴더를 훑습니다. ZIP, 7z, RAR, CAB도 이름으로 걸러지고 폴더는 남습니다. 아이콘이나 Alt+↓는 파일 종류입니다. 단축키는 설정 → 단축키에서 바꿀 수 있습니다. 화면 낭독기는 '패널 N 주소', '패널 N 검색'으로 읽습니다 |
| Num+ 또는 Ctrl+Shift+A / Num− / Num* | `*.jpg` 같은 패턴으로 선택, 선택 해제, 선택 반전. 개수는 상태줄에 5초 동안 남아요 |
| F6 / Shift+F6 | 다음 / 이전 포커스: 파일 목록, 주소, 필터, 폴더 트리, 즐겨찾기 |
| F3 | 빠른 미리보기. 사진, 텍스트·코드(줄 번호), 마크다운, CSV 표, Office·PDF·HTML·메일(10 MB까지), HWP·HWPX, ZIP 목록, 폴더를 보여 줍니다. 그 외는 정보 카드입니다. 방향키는 미리보기를 닫지 않고 이전·다음 파일로 옮기고, 휠이나 PgUp / PgDn은 스크롤합니다. Esc나 F3은 여는 중에도 바로 닫고 목록으로 돌아갑니다. 키를 누르고 있어도 한 번만 열립니다 |
| F7 | 새 폴더. 탐색기의 새 폴더라서 만들어지자마자 이름을 고칩니다 |
| Ctrl+Alt+T | 새 패널 탭(지금 폴더). 패널 안의 탭이 켜져 있고 포커스가 그 패널에 있을 때만 |
| Ctrl+Alt+W | 패널 탭 닫기 (마지막 하나는 남음) |
| Ctrl+Alt+Page Down / Ctrl+Alt+Page Up | 다음 / 이전 패널 탭 |
| Enter / Esc | 주소·필터 적용 / 취소 |
| Ctrl+H | 숨김 파일 표시 |
| Ctrl+Shift+E | 왼쪽 패널(폴더 트리와 즐겨찾기) 숨기기 / 보이기. 폭은 숨기기 전 그대로 |
| Ctrl+Shift+O | 열린 탐색기 창·탭의 폴더를 활성 패널부터 패널로 가져오기 (보기 메뉴도 가능, 이미 그 폴더를 연 패널은 그대로) |
| Ctrl+S | 지금 세션 저장 |
| Ctrl+B | 즐겨찾기 (↑/↓, Enter 열기, Del 빼기). 패널이나 이 목록에 포커스가 있으면 Alt+↑/↓로 선택한 줄을 옮깁니다. 패널에서 끌면 순서가 바뀌고, 밖에서 놓으면 취소됩니다 |
| Ctrl+Shift+M | 선택한 패널 크게 보기 / 복원 (머리줄 더블클릭도 가능) |
| Ctrl+Shift+C | 선택한 항목(없으면 현재 폴더)의 전체 경로 복사 |
| Ctrl+Alt+N | 새 텍스트 문서 |
| Ctrl+Shift+N | 새 폴더 |
| Ctrl+, | 설정 |
| Ctrl+/ | 단축키 목록. 앱과 같은 색의 창으로 열리고, 키를 누르고 있어도 한 번만 열려요 |
| F2, Del, Ctrl+C / X / V, F5 | 탐색기와 동일. 복사한 그림(스크린샷, 브라우저 이미지)을 Ctrl+V 하면 그 폴더에 PNG로 저장하고, 선택·포커스·폴더는 그대로 둡니다. 상태줄에 파일 이름이 나옵니다 |

패널의 빈 곳을 더블클릭하면 상위 폴더로 갑니다(보기 메뉴에서 끌 수 있음). 경계선 위에 마우스를 올리면 선택 색의 얇은 선이 나타납니다. 왼쪽 패널 가장자리와 폴더 트리·즐겨찾기 사이 구분선도 같습니다.

## 빌드

Rust GNU 툴체인(`x86_64-pc-windows-gnu`)과 MSYS2의 MinGW 도구(`C:\msys64\mingw64\bin`의 `windres`, `dlltool`, `as`)가 필요합니다.

```
build.cmd
```

`target\release\grids.exe`를 빌드해 `build\grids.exe`로 복사합니다. 앱 아이콘(`app.ico`)은 `icon.py`로 다시 그립니다.
