각 패널은 실제 Windows 탐색기 화면입니다. 우클릭 메뉴, 끌어다 놓기, 썸네일, 이름 바꾸기, 복사 진행 표시가 탐색기와 같습니다. 한 창에 패널을 최대 16개까지 띄우고, 왼쪽에는 폴더 트리, 배치는 끌어서 바꿉니다.

## 기능

- 🪟 **패널은 최대 16개.** 열 순서·너비·정렬은 폴더를 옮겨도 그 패널에 남습니다. 탐색기에서는 크기 열이 90 px에서 멈추지만, 여기서는 더 좁게 줄일 수 있습니다. 선택한 폴더의 크기는 상태줄에서 뒤에서 더합니다. F5로 다시 계산하고, 읽지 못한 항목이 있으면 '일부만'이라고 나옵니다.
- 🧩 **자유로운 배치.** 최대 4열, 열마다 1~4칸. 레이아웃을 누르면 칸이 균등해지고, 누른 채 끌면 열마다 칸 수를 정합니다. 자주 쓰는 배치는 프리셋 6개입니다. 새 탭은 지금 탭의 배치와 분할 비율을 그대로 가져옵니다.
- ↔️ **경계는 끌어서 조절.** 패널 사이, 사이드바 가장자리, 폴더 트리와 즐겨찾기 사이 구분선을 끌어 크기를 바꿉니다. 경계를 두 번 누르면 균등하게 나뉩니다. 왼쪽 패널의 위·아래는 각자 최소 높이를 유지합니다.
- ⭐ **폴더 트리와 즐겨찾기.** 트리는 활성 패널을 따라가고, 폴더가 깊어도 지금 폴더 이름이 보이게 스크롤합니다. 패널 머리줄의 별로 넣거나, 우클릭 메뉴에서 속성 바로 위의 즐겨찾기에 추가로 넣습니다. 그룹을 만들어 중첩하고, 항목을 그룹 사이로 끌어 옮길 수 있습니다. 폴더를 두 번 누르면 이 창에서 열고, 파일은 평소 쓰는 앱으로 엽니다.
- 🧭 **패널마다 도구줄.** 주소창, 뒤로·앞으로·상위, 이름 필터(`*.pdf;*.txt` 또는 이름 일부)가 있습니다. 주소창에는 `..`이나 하위 폴더, 파일 경로를 칠 수 있고, `cmd`·`wt`·`powershell`은 그 패널의 폴더에서 실행됩니다. 선택한 폴더를 다른 패널에서 열면 열 순서·너비·정렬도 함께 넘어갑니다. 선택한 파일은 다른 패널의 폴더로 복사하거나 이동합니다(최대 10,000개). 폴더를 패널 윗줄에 놓으면 그 패널에서 열립니다.
- 🔎 **Everything 검색.** 하위 폴더 검색은 [voidtools Everything](https://www.voidtools.com/)이 실행 중이면 Everything에 묻고, 아니면 디스크를 훑습니다. 검색하거나 설정을 열기 전에는 Everything을 불러오지 않으며, `Everything64.dll`도 쓰지 않습니다. 같은 칸이 지금 폴더의 필터이기도 합니다(`Ctrl+F`).
- 🗂️ **탭, 드라이브, 세션.** 탭 줄에는 창 탭, 드라이브 버튼(C: D: E: …), 레이아웃, 세션 저장, 세션 불러오기가 있습니다. 활성 패널의 드라이브에는 밑줄이 붙고, 드라이브를 꽂거나 빼면 버튼이 같이 생기고 사라집니다. 탭이 다 들어가지 않으면 펼침 단추로 모든 탭을 봅니다. 세션에는 배치, 폴더, 패널별 열이 저장되고, 카드에서 배치를 미리 봅니다. 카드 위에 마우스를 올리면 ✕로 지우고, 오른쪽 클릭으로 그 자리에서 이름을 바꿉니다. 이미 있는 이름은 덮어쓰지 않고 거부합니다. 저장하지 않은 배치는 저장 버튼의 초록 점으로 표시됩니다. 지워진 로컬 폴더는 남아 있는 가장 가까운 폴더로 열리고, 상태줄에 어떤 폴더가 없었는지 나옵니다. 패널 안의 탭은 그 패널에 폴더를 더 담습니다. 폴더가 하나면 탭 줄이 숨고, 둘 이상이면 머리줄 아래에 나옵니다.
- 👁️ **빠른 미리보기.** F3 또는 스페이스. 머리줄에 아이콘, 굵은 이름, 정보가 있습니다. 글·표·Office·HTML은 흰 판 위에, 사진과 PDF 쪽은 무대 위에 놓입니다. PDF는 Windows 내장 엔진이 최대 50쪽까지 그리고, 뷰어 도구 막대는 없습니다. 텍스트와 소스에는 줄 번호가 붙고, 마크다운은 짜임이 남으며, CSV/TSV는 표, ZIP과 폴더 목록은 줄무늬입니다. Office, HTML, Outlook 메일, 글꼴은 탐색기와 같은 미리보기 처리기를 씁니다. 처리기가 없으면 Word·Excel·PowerPoint·OpenDocument는 본문이나 첫 시트를, HWP·HWPX는 문서에 든 미리보기를, .eml은 머리글과 본문을 보여 줍니다. 그 외는 카드입니다. 10 MB가 넘는 문서는 건너뜁니다. 미리보기를 열기 전에는 불러오지 않고, Esc나 스페이스는 여는 중에도 바로 닫습니다.
- 🎨 **라이트, 다크, 패널 색.** 테마마다 선택 색이 6가지입니다. 활성 패널은 테두리와 머리줄 색으로 구분됩니다. 다크에서는 '장치 및 드라이브' 같은 묶음 제목이 밝은 글자와 가는 선으로 그려집니다. 새로 설치하면 Windows 설정을 따릅니다. 다크 테마나 라이트 테마를 고르면 직접 고정되고, 따라가기는 꺼집니다. 패널 머리줄의 빈 곳이나 번호를 오른쪽 클릭해 여섯 색 중 하나(또는 없음)를 고릅니다. 색은 세션에 저장되며 탭 색과는 별개이고, ⇄ 메뉴에 색 이름이 나옵니다.
- 📦 **작은 exe 하나.** 약 450 KB이고, 설치하지 않습니다. Ctrl+N으로 같은 프로세스에 새 창을 열고, `grids.exe`를 다시 실행해도 마찬가지입니다. 창마다 탭이 따로 있습니다. 탭을 밖으로 끌면 다른 창으로 옮깁니다. 마지막 창을 닫으면 모든 창이 다음 실행에 돌아옵니다. 창 하나만 쓰기를 켜면 창은 하나입니다. Win+Alt+E는 어느 앱에서나 Grids를 앞으로 가져오고, 다시 누르면 최소화합니다.

## 설치

[https://github.com/Samek86/grids](https://github.com/Samek86/grids)에서 `grids.exe`를 받아 아무 폴더에 두고 실행합니다. 설치 없이 쓰는 exe 하나이고, 크기는 약 450 KB입니다.

코드 서명이 없는 exe라 처음 실행할 때 Windows SmartScreen 경고가 뜰 수 있습니다. **추가 정보 → 실행**을 누르세요.

**요구 사항:** Windows 10(1903 이상) 또는 Windows 11, x64.

설정은 `%APPDATA%\grids\grids.json`에 있습니다. `grids.exe` 옆에 `portable.txt`라는 파일을 두면 `grids.json`을 exe 옆에 둡니다. 이름 붙인 세션은 exe 옆 `sessions` 폴더의 `.grids` 파일로 남습니다.

## 소스에서 빌드

Rust GNU 툴체인(`x86_64-pc-windows-gnu`)과 MSYS2의 MinGW 도구(`C:\msys64\mingw64\bin`의 `windres`, `dlltool`, `as`)가 필요합니다.

```
build.cmd
```

`target\release\grids.exe`를 빌드해 `build\grids.exe`로 복사합니다. 앱 아이콘(`app.ico`)은 `icon.py`로 다시 그립니다.

## 단축키

아래는 기본값입니다. 설정 → 단축키에서 바꿀 수 있고, 바꾼 키는 바로 동작합니다. 주소창, 필터, 탭 이름을 입력하는 동안에는 단축키가 동작하지 않습니다. F6은 그 칸에서도 포커스를 옮깁니다. 다른 앱에 갔다 키보드로 돌아오면 목록, 주소, 필터, 폴더 트리, 즐겨찾기 중 떠나기 전 자리로 포커스가 돌아옵니다. 클릭으로 돌아오면 그 클릭이 컨트롤을 받지 않았을 때만 되돌립니다. 주소와 필터의 글자와 커서는 그대로입니다.

| 키 | 동작 |
| --- | --- |
| Ctrl+T | 새 탭 (지금 탭의 레이아웃으로) |
| Ctrl+W | 탭 닫기 (잠긴 탭은 그대로) |
| Ctrl+Tab / Ctrl+Shift+Tab | 다음 / 이전 탭 |
| Ctrl+Shift+T | 마지막으로 닫은 탭 다시 열기 |
| Ctrl+PageDown / Ctrl+PageUp | 다음 / 이전 패널 |
| Ctrl+1 … Ctrl+9 | 1~9번 패널로 이동 (패널 머리줄 왼쪽의 번호, 아주 좁은 패널에서는 생략) |
| Alt+Shift+← / → / ↑ / ↓ | 왼쪽·오른쪽·위·아래 패널로 이동 |
| Ctrl+Alt+Shift+← / → / ↑ / ↓ | 지금 패널을 그 방향의 패널과 자리 바꾸기 (폴더·방문 기록·필터·열이 유지되고, ⇄ → 자리 바꾸기에도 있음). 저장하거나 다시 바꾸기 전까지 저장 점이 남고, 다시 시작해도 그대로입니다 |
| Alt+← / Alt+→ | 뒤로 / 앞으로 |
| Alt+↑ | 상위 폴더 |
| Alt+↓ | 최근 폴더 (모든 패널, 최근 순, ← / → 오른쪽 클릭도 가능) |
| Ctrl+L, Alt+D, F4 | 주소창. 칸이 넓으면 왼쪽에 현재 폴더 아이콘이 붙습니다. 가만히 있으면 `C: › Users › Public`처럼 경로 조각으로 보입니다. 조각을 누르면 그 폴더로, › 는 그 안의 폴더 목록(지금 패널이 연 폴더는 굵게), `…`는 접힌 상위 폴더, 현재 폴더나 빈 곳은 경로 입력입니다. 느린 폴더도 창을 멈추지 않고, 메뉴 위치는 열기 직전에 다시 잡습니다. 창 크기나 DPI가 바뀌면 취소됩니다. `..`, 하위 폴더, 열 파일, `cmd`·`wt`·`powershell`도 가능합니다(이 패널 폴더에서 실행). `down`처럼 이름 일부만 치면 최근 폴더로, 없으면 즐겨찾기 트리의 폴더로 이동합니다 |
| Ctrl+F | 이 폴더를 검색합니다(같은 칸이 목록 필터이기도 합니다). 비어 있으면 '검색 · Ctrl+F'가 흐리게 보이고, 입력하거나 포커스를 주면 사라집니다. 단어는 이름 어디에든 맞고, `*`와 `?`는 와일드카드, `;`는 둘 중 하나이며, 대소문자는 구분하지 않습니다. 입력하는 동안 결과가 이어지고, 다시 입력하거나 Esc면 검색이 취소됩니다. 폴더를 훑는 검색은 300개에서 멈추고 더 있다고 알려 주며, Everything은 5,000개에서 멈춥니다. Enter나 더블클릭은 파일을 열고(그 파일이 있는 폴더로 패널이 이동합니다) 폴더는 이 패널에서 엽니다. 결과 목록의 하위 폴더는 아래 폴더까지 찾습니다. Everything이 실행 중이고 검색에 Everything 사용이 켜져 있으면(설정 → 일반, 기본값은 켜짐) Everything에 묻고 목록에 Everything이라고 나오며, 아니면 폴더를 훑고 폴더라고 나옵니다. Everything 문법(`ext:`, `size:`, `dm:`, `regex:`, `path:`)은 그대로 전달됩니다. 목록의 이 폴더 / 모든 드라이브, 또는 `all:`로 시작하는 검색은 이 폴더와 색인된 모든 드라이브 중 범위를 고릅니다. ZIP, 7z, RAR, CAB도 이름으로 걸러지고 폴더는 남습니다. 아이콘이나 Alt+↓는 파일 종류입니다. 단축키는 설정 → 단축키에서 바꿀 수 있습니다. 화면 낭독기는 '패널 N 주소', '패널 N 검색'으로 읽습니다 |
| Num+ 또는 Ctrl+Shift+A / Num− / Num* | `*.jpg` 같은 패턴으로 선택, 선택 해제, 선택 반전. 개수는 상태줄에 5초 동안 남습니다 |
| F6 / Shift+F6 | 다음 / 이전 포커스: 파일 목록, 주소, 필터, 폴더 트리, 즐겨찾기 |
| F3 / Space | 빠른 미리보기. 사진, 텍스트·코드(줄 번호), 마크다운, CSV 표, Office·PDF·HTML·메일(10 MB까지), HWP·HWPX, ZIP 목록, 폴더를 보여 줍니다. 그 외는 정보 카드입니다. 방향키나 휠은 미리보기를 닫지 않고 이전·다음 파일로 옮깁니다. 긴 글에서는 휠이 먼저 스크롤하고, 끝에서 350 ms 머물면 다음 파일로 넘어갑니다. 휠을 기울이면 항상 파일로 넘어갑니다. PgUp / PgDn은 스크롤합니다. Esc, 스페이스, F3은 여는 중에도 바로 닫고 목록으로 돌아갑니다. 키를 누르고 있어도 한 번만 열립니다. 글자를 입력한 뒤 1초 안의 스페이스나 IME 조합 중에는 이름의 일부로 들어갑니다. 설정 → 패널·보기에서 스페이스를 끌 수 있습니다(`space_preview`, 키가 없으면 켜짐) |
| F7 | 새 폴더. 탐색기의 새 폴더라서 만들어지자마자 이름을 고칩니다 |
| Ctrl+Alt+T | 새 패널 탭(지금 폴더). 포커스가 그 패널에 있을 때. 탭이 하나면 ⇄ 오른쪽 버튼도 같습니다 |
| Ctrl+Alt+W | 패널 탭 닫기 (마지막 하나는 남음) |
| Ctrl+Alt+Page Down / Ctrl+Alt+Page Up | 다음 / 이전 패널 탭 |
| Enter / Esc | 주소·필터 적용 / 취소 |
| Ctrl+H | 숨김 파일 표시 |
| Ctrl+Shift+E | 왼쪽 패널(폴더 트리와 즐겨찾기) 숨기기 / 보이기. 폭은 숨기기 전 그대로 |
| Ctrl+Shift+O | 열린 탐색기 창·탭의 폴더를 활성 패널부터 패널로 가져오기 (보기 메뉴도 가능, 이미 그 폴더를 연 패널은 그대로) |
| Ctrl+S | 지금 세션 저장 |
| Ctrl+B | 즐겨찾기 (↑/↓, Enter 열기, Del 빼기). 패널이나 이 목록에 포커스가 있으면 Alt+↑/↓로 선택한 줄을 옮깁니다. 패널에서 끌면 순서가 바뀌고, 밖에서 놓으면 취소됩니다 |
| Ctrl+Shift+M | 선택한 패널 크게 보기 / 복원 (머리줄 더블클릭도 가능) |
| Ctrl+Shift+C | 선택한 항목(없으면 현재 폴더)의 전체 경로 복사 |
| Ctrl+Alt+N | 새 텍스트 문서 |
| Ctrl+Shift+N | 새 폴더 |
| Ctrl+, | 설정 |
| Ctrl+/ | 단축키 목록. 앱과 같은 색의 창으로 열리고, 키를 누르고 있어도 한 번만 열립니다 |
| F2, Del, Ctrl+C / X / V, F5 | 탐색기와 동일. 복사한 그림(스크린샷, 브라우저 이미지)을 Ctrl+V 하면 그 폴더에 PNG로 저장하고, 선택·포커스·폴더는 그대로 둡니다. 상태줄에 파일 이름이 나옵니다 |

패널의 빈 곳을 두 번 누르면 상위 폴더로 갑니다(보기 메뉴에서 끌 수 있습니다). 경계선 위에 마우스를 올리면 선택 색의 얇은 선이 나타납니다. 왼쪽 패널 가장자리와 폴더 트리·즐겨찾기 사이 구분선도 같습니다.

## 설정

탭 줄의 톱니가 보기 메뉴를 엽니다. 설정은 그 메뉴에 있습니다(`Ctrl+,`).

설정은 `%APPDATA%\grids\grids.json`에 저장됩니다. `grids.exe` 옆에 `portable.txt`를 두면 `grids.json`도 exe 옆에 둡니다. 이름 붙인 세션은 exe 옆 `sessions` 폴더의 `.grids` 파일입니다. 기존 `grids.ini`는 한 번 읽은 뒤 `grids.ini.bak`으로 바꿉니다. 예전 `grids.ini`의 `lang=ko`도 한국어로 읽힙니다.

파일은 원자적으로 바뀝니다. 저장이 실패하면 5초 뒤에 다시 시도합니다. 읽지 못하는 파일은 기본값으로 덮지 않고, 다시 시도하거나 종료합니다. 모르는 키는 그대로 둡니다. 최소화해도 최대화였으면 최대화로 기억합니다.

언어는 자동(Windows 표시 언어), English, 한국어, 日本語이고, `"lang": "auto"`, `"en"`, `"ko"`, `"ja"`로 저장됩니다. 패널 안의 탐색기 부분(열 이름, 우클릭 메뉴)은 Windows 표시 언어를 따릅니다. 글꼴은 그 언어의 기본 글꼴(Segoe UI, 맑은 고딕, Yu Gothic UI)에서 시작하고, 고르면 창 전체에 바로 적용됩니다(`font_face`). 글꼴 크기 설정은 없으며, 예전 `font` 값은 무시합니다.

보기 메뉴의 파일 확장명 표시는 탐색기와 같은 Windows 설정이고, 설정 창에도 있습니다. 새로 설치하면 보기 메뉴의 Windows 라이트·다크 설정 따르기가 그 체크입니다. 다크 테마나 라이트 테마를 고르면 직접 바꾸고 따라가기를 끕니다. 목록은 그 자리에서 다시 칠하므로, 이동 기록, 필터, 선택, 스크롤, 입력 중인 주소가 남습니다.

| 키 | 설명 |
| --- | --- |
| `side_split` | 폴더 트리와 즐겨찾기 사이 구분선. 다시 열 때 돌아옵니다. 왼쪽 패널 전체는 설정에서 숨길 수 있습니다. |
| `use_everything` | `"use_everything": false`가 없으면 켜져 있습니다. 켜져 있으면 하위 폴더 검색이, Everything이 실행 중일 때 Everything에 묻습니다. 설정 → 일반에는 설치되어 실행 중, 설치되어 있지만 실행 중이 아님, 설치되어 있지 않음이 나오고, Everything이 버전을 알려 주면 함께 표시됩니다. Everything 시작은 설치된 `Everything.exe`를 실행합니다. 설치는 winget이 있으면 `winget install --id voidtools.Everything -e`를 실행하고, 없으면 voidtools 다운로드 페이지를 엽니다. |
| `ev_asked` | Everything 설치를 한 번만 물은 답을 기억합니다. Everything이 없을 때 처음 하위 폴더 검색을 하면 설치할지 묻습니다. |
| `drive_buttons` | 키가 없으면 켜짐. 설정 → 모양 → 드라이브 버튼 표시를 끄면 버튼이 숨고 그 자리를 탭이 씁니다. 창이 좁으면 뒤쪽 글자부터 숨깁니다. |
| `layout_new` | 첫 실행과 새 창의 기본 레이아웃. 좌우 2개, 위아래 2개, 2×2, 1개 중 하나입니다. 다른 실행에서 넘겨받은 경로는 1패널 탭으로 열립니다. 창 탭을 새로 만들면(+ 또는 Ctrl+T) 기본 레이아웃 대신 지금 탭의 배치를 가져옵니다. |
| `hotkey` | 줄이 없으면 켜짐. Win+Alt+E로 Grids를 앞으로 가져오고, 다시 누르면 최소화합니다. Grids 대화 상자가 열려 있으면 그 창이 앞으로 옵니다. 보기 메뉴의 체크는 키가 실제로 등록됐을 때만 켜지므로, 시작에 실패해도 한 번 누르면 다시 시도합니다. 단축키는 설정에서 바꿀 수 있습니다. |
| `space_preview` | 키가 없으면 켜짐. 설정 → 패널·보기 → 스페이스로 미리보기를 끄면 스페이스로는 열리지 않습니다. 글자를 입력한 뒤 1초 안의 스페이스나, 한글·일본어를 조합하는 중의 스페이스는 이름의 일부로 들어갑니다. Ctrl+Space와 Shift+Space는 그대로 둡니다. |
| `folders` | 패널 안의 탭으로 연 폴더. 패널마다 저장되고, 이름 붙인 세션에도 들어갑니다. 예전 `pane_tabs` 값은 무시됩니다. |
| `favorites_tree` | 즐겨찾기 트리. 예전 목록은 맨 위로 옮겨집니다. |
| `one_window` | 창 하나만 쓰기. 줄이 없으면 꺼져 있습니다. 켜면 다시 실행할 때 최소화된 창을 되돌리고, 경로 인자는 그 창의 탭으로 엽니다. Ctrl+N, 탭을 밖으로 끌기, 새 창으로 이동, 이미 앞에 있을 때의 Win+Alt+E는 새 창 대신 이 창의 탭을 엽니다. |
| `lang` | `"auto"`, `"en"`, `"ko"`, `"ja"`. |
| `font_face` | 창 전체의 글꼴. 글꼴 크기는 저장하지 않습니다. 예전 `font` 값은 무시됩니다. |

## 로드맵

- [ ] `grids.exe`에 코드 서명을 넣어, 처음 실행할 때 SmartScreen 경고가 나오지 않게 합니다
- [ ] 글꼴 크기 설정. 지금은 글꼴 이름(`font_face`)만 저장됩니다
- [ ] English, 한국어, 日本語 이외의 표시 언어

## 감사

Grids는 efww의 [grids](https://github.com/efww/grids)를 포크한 프로그램입니다.

[Q-Dir](https://www.softwareok.com/?seite=Freeware/Q-Dir)와 [voidtools Everything](https://www.voidtools.com/)에서 영감을 받았습니다. Grids는 Q-Dir 및 그 제작자와 관계없는 독립 프로젝트입니다.
