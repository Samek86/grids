# Grids

다중 패널 파일 관리자 (Rust, Win32). 각 패널이 Windows 탐색기 컨트롤(IExplorerBrowser)이라 우클릭 메뉴·드래그 앤 드롭·썸네일은 Windows 그대로입니다. 설치 없이 exe 하나로 실행되고, 설정은 exe 옆 `grids.ini`에 저장됩니다.

- 왼쪽 폴더 트리(활성 패널 폴더를 따라감) + 최대 4열 × 열마다 1~4칸
- 레이아웃 버튼: 클릭 = 균등 배치, 누른 채 끌기 = 열마다 칸 수, 프리셋 6개
- 경계 드래그로 크기 조절(놓을 때 배치), 경계 더블클릭 = 균등 분할
- 패널별 주소창·뒤로/앞으로/상위·이름 필터, ⇄ 다른 패널에서 열기, 빈 곳 더블클릭 = 위 폴더(끄기 가능)
- 활성 패널: 선택 색 테두리 + 헤더 틴트(보기 → 선택 색, 라이트·다크 각각 6색)
- 라이트(상아색 틀) / 다크 테마: 툴바 맨 오른쪽 해·달 버튼
- 세션: 자동 저장 + 이름 붙인 세션(.grids). 저장 버튼(Ctrl+S)은 배치가 바뀌면 초록 점, 불러오기는 배치 미리보기 카드
- 단일 인스턴스, 상태바, 앱 아이콘(`icon.py`로 생성 → `app.ico`)
- 단축키: 보기 → 단축키

## 빌드

Rust GNU 툴체인 + msys2(`C:\msys64\mingw64\bin`: windres·dlltool·as)가 필요합니다.

```
build.cmd
```

`target\release\grids.exe`를 빌드해 루트에 `grids.exe`로 복사합니다.
